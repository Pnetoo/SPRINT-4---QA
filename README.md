# Sprint 4 - Compliance & Quality Assurance

## Projeto EcoTrack

O EcoTrack é uma solução web/mobile voltada à consulta de informações nutricionais e ambientais de produtos, permitindo busca por nome ou código de barras, visualização de detalhes, recomendações de alternativas mais saudáveis e sustentáveis, histórico de consumo e dashboards administrativos.

## Parte A - Testes Manuais

Os testes manuais foram cadastrados no Azure Boards como Work Items do tipo Issue, vinculados ao Epic:

SPRINT 4 - Compliance & Quality Assurance

Foram criados 10 casos de teste contemplando:

- Login com usuário válido
- Login com senha inválida
- Busca de produto pelo nome
- Busca por código de barras
- Produto inexistente
- Visualização de detalhes nutricionais e ambientais
- Consulta de alternativas saudáveis e sustentáveis
- Registro no histórico de consumo
- Consulta do histórico de consumo
- Dashboard administrativo de insights agregados

## Parte B - Testes Automatizados

Foram criados 4 casos de testes automatizados utilizando Postman:

1. AT01 - Buscar produtos
2. AT02 - Consultar detalhes do produto
3. AT03 - Registrar produto no histórico
4. AT04 - Consultar histórico de consumo
