# Sprint 4 - Compliance & Quality Assurance

## Projeto EcoTrack

O EcoTrack é uma solução web/mobile para consulta de informações nutricionais e ambientais de produtos, permitindo busca por nome ou código de barras, visualização de detalhes, recomendações de alternativas mais saudáveis e sustentáveis, histórico de consumo e dashboards administrativos.

## Parte A - Testes Manuais

Os testes manuais foram cadastrados no Azure Boards como Work Items, vinculados ao Epic:

SPRINT 4 - Compliance & Quality Assurance

Foram criados 10 casos de teste manuais, contendo:
- testes planejados;
- dados de entrada;
- dados de saída esperados;
- procedimento de execução.
